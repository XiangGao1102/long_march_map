# 长征地图：单入口精简版

本包只有一个网页入口：index.html。它包含当前完整网页，直接打开即可。

上传部署：将本包解压后的全部文件和 assets、css、js 文件夹一起上传到网站目录，保持它们在同一层。部署后使用网站目录网址，或目录下的 index.html。此前的 index_*.html 版本入口已删除。

本地预览：直接打开 index.html；也可运行 start-local.bat（Windows）或 start-local.sh（macOS/Linux），再访问 http://127.0.0.1:8000/ 。启动脚本使用本机 Python。

所有路线、43 个节点、介绍文字、Word 原图、时间轴、地图位置和现有交互保持上一版。金沙江、五岭的蓝色圆圈、实心圆心、双光晕、闪烁、粗实心箭头、金色诗句及跳转链接都已保留。顶部“万水千山只等闲”标题仍可点击打开原有 KIMI 搜索链接。

assets 中保留了实际使用的节点预览小图、点击放大的 Word 原图、地图纹理、沉浸式地图、音频和图标。js 中的本地纹理资源用于直接打开本地文件，css 和其他 js 负责网页显示及交互，均保持原有结构。

manifest.clean-*.webmanifest 用于手机添加到主屏幕；deployment-version.json 用于核对部署版本。手机全屏方式见“全屏使用说明.txt”。
