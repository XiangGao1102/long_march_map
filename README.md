# 长征地图：资料栏版·卡顿与图片延迟优化

基于“long_march_map_资料栏收起再展开修正版.zip”完成优化，保留三条路线、43 个节点、时间轴、地图位置、介绍文字、图片对应关系、界面样式及原有操作。

针对卡顿：减少地图标签、时间轴和歌词的重复刷新；优先处理资料栏滚动；减少手机路线播放的重复绘制；查看大图、进入沉浸式界面或切到后台时暂停被遮挡的三维绘制；避免重复调整绘制尺寸。

针对节点图片比文字晚显示：使用适合手机展示的轻量小图，首图立即加载，提前准备当前路线附近节点的图片。保留全部 37 张 Word 原图，点击放大仍打开原图。首次打开没有缓存的图片仍需下载，因此加载时间也会受网络速度影响。

已经核对指定压缩包与优化后程序，确保路线、节点顺序、日期、介绍文字和原图对应关系没有改变。采用与已通过 WebKit、Chrome 模拟浏览器检查一致的程序和资源；包含节点、横竖屏、开场引导、资料栏再次展开、沉浸式界面和本地打开检查。

部署时解压本包，将全部文件和文件夹上传到同一个网站目录，保持目录结构。index.html 是默认首页的小入口，自动打开完整网页 index_fast_20261011.html，两者均需保留。assets、css、js 与这两个文件放在同一层。目录链接及直接打开 index_fast_20261011.html 均可使用。

本包去掉了不需要部署的历史记录、旧版程序、重复副本和已不再引用的旧图片。需要的小图与原图、不同分辨率的地图和本地打开资源均已保留。
